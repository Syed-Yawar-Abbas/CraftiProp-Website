# CraftiProp Website

The responsive CraftiProp property discovery website, built with Next.js.

## Run locally

Requires Node.js 18.17 or later.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). To create and run a production
build, use `npm run build` followed by `npm start`.

## GitHub Pages

The site is deployed from the `main` branch with GitHub Actions at
